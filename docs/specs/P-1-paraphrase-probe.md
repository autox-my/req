# P-1 — measure Tier-1 against independent paraphrase without human labelling time

Task id: `P-1` (a measurement, not a milestone). Code baseline: current `main`. Owner constraint of
2026-11-03: human attention is scarce, so the independent-paraphrase measurement cannot depend on
people writing restatements. This unit builds the instrument that gets a better number than the
rule-derived corpora without them, and says plainly what grade of evidence it is.

## Why

Every equivalent pair in `external-v1..v4` is generated by the transforms Tier-1 implements, so a 0%
false-split rate there is a tautology. The open question is how often *independently worded* text for
the same obligation fails to share an address.

**A first number already exists, from data in the repo.** `bench/corpus/tier2-positives-v1.yml` holds 15
authored restatements of real requirement statements (and 14 one-element alterations). Run through
`req bench` in a scratch root on 2026-11-03: **0 of 15 restatements share an address (false-split rate
15/15 = 100%); 0 of 14 alterations collapse (false merges 0).** Limits, stated with the number:
15 pairs, one author (an agent, pseudonym `bob`), labels *informed* not blind, and Tier-1's own
scope excludes paraphrase/voice/word order by design. It says: Tier-1 does not collapse independent
paraphrase, and the question left is **why** and **how much a cheap rule extension could recover**.

## What to build

1. **Sampler.** From `bench/corpus/external-v3.yml`'s `a` sides (real prose, pinned by commit), draw
   **60 statements** deterministically (`sha256(pair id)` ordering, then take the first 60 that are
   single-obligation `shall`/`must` sentences of 6–40 words). Write `experiments/paraphrase/statements.json`
   with ids and source citations. No statement may come from a pair id the rules were tuned on if that
   is detectable; say how you checked.
2. **Generator protocol.** Each *generator* is a model that sees only: the statement, and the
   instruction "restate this requirement as a different engineer would write it, preserving exactly
   the same obligation (who, modality, action, bound, condition); do not copy phrasing; give 3
   restatements; then give 1 alteration that changes exactly one element (modality, quantity,
   actor, action or condition) and name which element". **Generators are never shown Tier-1's rules
   or any canonical form** (neither to help nor to hurt it). Output: `experiments/paraphrase/restatements/<generator-id>.json`.
   The orchestrator runs the generators on at least three model families; the unit builds the
   protocol document, the output schema, and a validator, and does not itself call a model.
3. **Judge filter.** A second model family judges each (statement, restatement) pair: *same
   obligation? yes / no / unsure*. Only unanimous `yes` restatements enter the headline; the rest are
   counted and listed. (Reason: a generator can drift in meaning; a drifted "restatement" correctly
   splits.) Output: `experiments/paraphrase/judgements/<judge-id>.json`.
4. **Scorer** (`experiments/paraphrase/`, a small Rust crate depending on `req` by path, same pattern as
   `experiments/tier2` if M2-2 has landed, own lockfile, **root `Cargo.toml`/`Cargo.lock` untouched**):
   `req-paraphrase score …` canonicalizes each statement and restatement through the public
   `canonicalize_statement` seam and reports, **per generator, never pooled**:
   - false-split rate = restatements (judge-confirmed) with a different address / total, with the
     counts and a 95% Wilson interval;
   - the same split by `structured` vs `unstructured` side;
   - for each false split, **which canonical-form fields differ** (subject, action, qualifier,
     modality, value/unit), and the top 10 most frequent difference *shapes* with 2 examples each —
     this is the actionable output (a ranked list of rules that would recover the most pairs);
   - false merges on the alterations (an altered statement sharing the original's address is a false
     merge: always reported by id, FMR must be 0; a collapse is a finding, never averaged away);
   - coverage: restatements generated / judged yes / excluded, per generator.
5. **Honest record.** `experiments/paraphrase/results/<result-named>.json` (named by content, not by
   clock, like `tools/tier2/evaluate.py`; a second identical run refuses to overwrite) and a
   `experiments/paraphrase/README.md` that states the grade of the evidence: *model-authored
   paraphrase, blind to Tier-1, judge-filtered; not human; generators share training-data biases; the
   headline is a lower bound on how far real writers diverge, not an estimate of it.* No claim of
   validation or refutation of the bet.
6. **`--self-check`** table-driving the pure half (interval, difference-shape bucketing, filter).
   Optional step in `scripts/check.sh` only if it costs under 3 s; otherwise a documented manual
   command. The experiment never feeds the release gate.

## Red test

`--self-check` cases written first with hand-computed expected values (a Wilson interval for 3/10,
a bucket assignment for two canonical forms that differ only in `qualifier`, a filter that drops a
`unsure` restatement), failing before the functions exist.

## Verify

Full `scripts/check.sh`, exit 0, no SKIP, baseline `[VERIFIED]` (nothing here moves an address).
The scorer runs end to end on a **fixture** of 3 statements with hand-written restatements checked
in under `experiments/paraphrase/fixtures/` (the real generator outputs are produced afterwards by
the orchestrator and committed in a follow-up).

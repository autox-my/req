What req does when a requirement changes

req links each part of a design to the requirement it was built to meet, and when that requirement’s meaning changes it says in which direction, so a person is asked to re-check a link only when the change could break it. Below, one real requirement is edited three ways on a copy: a tool that flagged every edit would raise the alarm on all three, and req raises it on one.

What SUSPECT means

SUSPECT means the part was recorded against a claim whose meaning has since tightened or changed in another direction.

It does not mean the part is wrong; it means a person must re-check it and re-record the link.
